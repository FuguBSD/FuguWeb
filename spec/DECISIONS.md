# Decisions

This document holds the decisions that govern FuguWeb. A plan must not go
against a decision. To change a decision, propose the change and get human
approval first.

| ID   | Decision                                                                                                                                                                                                  | Rationale                                                                                                                                                                                                                                |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-01 | The site output is plain HTML and one stylesheet: no templating language and no JavaScript.                                                                                                               | The output stays auditable, and every renderer stays replaceable.                                                                                                                                                                        |
| D-02 | The signify key of the `root` purpose is the root of trust of a key directory. Every other key of the directory binds to it.                                                                              | One line holds a signify key, so a consumer pins it with one line, and one small tool verifies it on every platform. An OpenPGP key and an X.509 certificate each bring an issuer or a web of trust that a consumer must learn first.    |
| D-03 | The key verbs read and write each private key as a file, and hold no secret store.                                                                                                                        | A workflow writes a secret into a file and reads one back. The verbs then serve GitHub Actions, a vault, and a shell the same way.                                                                                                       |
| D-04 | The content HTML carries no class, and the stylesheet styles element names. The classes that `mandoc` emits are the one exception.                                                                        | A body fragment from a hand, from `lowdown`, or from `pod2man` gets the full style with no markup contract, and a new renderer needs none.                                                                                               |
| D-05 | The description declares each language, and the first one is the default. Every page of the description renders in the tree of each language. A description that declares none has the one language `en`. | A site with one language and a site with ten take one layout. No path moves when a translation arrives. One tag names a language in the path, in `lang` and in `hreflang`.                                                               |
| D-06 | A translation follows the outline of its source, and each heading takes the id of its counterpart in the default language.                                                                                | One link to a fragment works in each language. A translation that drifts from its source fails the build, and no link breaks in silence.                                                                                                 |
| D-07 | A body fragment holds the content only. The build removes the frame that a renderer writes around the content, and each word of that frame.                                                               | Each word of a page then comes from the project, in the language of the page. The sheet adds one word, the program name `xterm`, per WEB-LANGUAGE-12. The fit of each renderer stays in one function, so the renderer stays replaceable. |
