=head1 NAME

App::FuguWeb::Page - the shared chrome around one body fragment

=head1 SYNOPSIS

    use App::FuguWeb::Page;

    my $page = App::FuguWeb::Page->new(
        config   => $config,
        language => $config->language('zh-Hans'),
        footer   => $footer);

    $page->write("$out/zh-hans/install.html", 'Install', $fragment,
        name => 'install.html');

=head1 DESCRIPTION

Every source format is reduced to one HTML body fragment, and this
class wraps it: the head, the header, the navigation, the fragment, and
the footer. The layout is fixed. What a project decides is the site
name, the languages, the navigation, and the footer prose.

The class builds the document as characters, with string operations,
not with a substitution over a template. A title may therefore hold any
character, including the slash and the ampersand that a C<sed> template
could not take. The write encodes the document to UTF-8, per
WEB-SITE-5.

Two separators are not ASCII: an em dash between the page title and the
site name, and a middle dot between navigation entries. Both are
character constants, and the encode writes their bytes.

The title, the site name and every navigation label go through
L<App::FuguWeb/escape_html>.

=head1 METHODS

=head2 new

    App::FuguWeb::Page->new(config => $config, language => $language,
        footer => $html)
    App::FuguWeb::Page->new(config => $config, kind => 'keys')
    App::FuguWeb::Page->new(config => $config, kind => 'top')

C<config> is an L<App::FuguWeb::Config> and is required.

C<language> is the L<App::FuguWeb::Language> of a tree page, and it
defaults to the default language of the site. The chrome takes the site
name and the navigation labels of that language.

C<footer> is the footer fragment of that language, as characters.
L<App::FuguWeb::Site> reads it, and a tree page carries it. A page
without one carries no footer.

C<kind> is the kind of the page, and it decides the form of each
relative link of the chrome. An absolute URL and a fragment stay as
they stand. The tree below is the path of the default tree.

    kind    the page                        a link          the sheet
    tree    <path>/<page>                   <page>          ../style.css
    keys    <dir>/index.html, the key page  ../<tree>/<page> ../style.css
    top     404.html at the top level       <tree>/<page>   style.css

A tree page names each page of its own tree. The key page and the
top-level copy of the 404 page link the default tree, and their chrome
takes the words of the default language. The C<top> page also carries
C<< <base href="/"> >>. A host serves it at each path that no file
answers, and the base makes each relative link resolve from the root of
the origin.

The constructor dies for an unknown kind.

=head2 write

    $page->write($path, $title, $fragment, %page)

Write the whole page with L<Fugu::File>: the chrome around the
fragment, encoded to UTF-8. The fragment goes in unchanged: it is
already HTML, from a renderer or from the project's own source
directory. The method returns true on success, and C<undef> with a
message in the log otherwise. The page arguments are those of
L</document>.

=head2 document

    $page->document($title, $fragment,
        name      => 'install.html',
        body_lang => 'en')

The whole page as characters. A caller that writes the file itself, or
that holds the page beside other generated bytes, reads the document
here and never repeats the chrome.

C<name> is the name of the page in its tree. A tree page of a site of
more than one language links the same page in each other language, so
it needs the name, and the method dies without it.

C<body_lang> is the tag of the language of the fragment, and it
defaults to the language of the page. A fragment of another language
carries the marks of L</THE LANGUAGE OF EACH PART> on the
C<< <main> >> element. The parts of an index page come from more than
one language, so L<App::FuguWeb::Site> passes the language of the tree
for it. L<App::FuguWeb::Index/body> marks each part of another
language.

=head1 THE LANGUAGE OF EACH PART

The C<< <html> >> element of a page carries the tag of its language as
C<lang>, and C<dir="rtl"> when that language is right to left, per
WEB-LANGUAGE-10. A tree page is a page of its language, and the copy of
the 404 page a page of the default language. The key page is a page of
C<en>, because its own words are English, per WEB-CHROME-8.

A part of the chrome whose text comes from another language than the
page carries the marks of that language, per WEB-LANGUAGE-11: the tag
as C<lang>, and its direction as C<dir> when the two directions
differ. The part is the site link of the header, the link of a
navigation label, the C<< <main> >> of a body, or the
C<< <footer> >>.

    <a href="manuals.html" lang="en" dir="ltr">Manuals</a>

=head1 THE LANGUAGE LINKS

A tree page links the same page in the tree of each other language of
the site. The links follow the navigation entries, in the order of
L<App::FuguWeb::Config/languages>:

    <a href="../zh-hans/install.html" hreflang="zh-Hans">zh-Hans</a>

The tag is the text and the C<hreflang> of each link, and the path of
the tree is the tag in lowercase. A site of one language carries no
such link, and neither does a page of another kind.

=head1 THE OPTIONAL FOOTER

The C<footer> setting of the description names the footer fragment, and
a C<language> block can name the fragment of its language. A project
without one gets no C<< <footer> >> element and no rule before one: an
empty footer is a gap, not chrome.

A tree page carries the footer, and a page of another kind carries
none, per WEB-KEYS-32. The prose is the project's own, and this class
copies it in unchanged. A relative link inside it resolves against the
directory of the page. Inside a tree it names a page of that tree. On
the key page it would name a file of the key directory, and on the
top-level copy of the 404 page a file of the root. The writer of the
fragment named neither.
